HYBRID MZI PHYSICAL-MODEL DIAGNOSTIC / HANDOFF FOR CODEX
Date: 2026-09-09

PURPOSE
-------

The goal of the next modeling pass is NOT to fit optical parameters until the simulated output resembles the measured system.

The goal is the opposite:

    MEASURE THE PHYSICAL SYSTEM -> BUILD THE MODEL FROM THOSE MEASUREMENTS
    -> CHECK WHETHER THE MODEL REPRODUCES THE OBSERVED BEHAVIOR.

We want to determine whether the phase-dependent amplitude observed in the hybrid Mach-Zehnder interferometer can be reproduced from physically accurate, independently measured parameters.

The model should be treated as a forward physical model, not as a curve-fitting device.

A successful outcome is:

1. Each model parameter corresponds to a clearly defined physical quantity.
2. Each quantity is independently measured whenever practical.
3. Power measurements are converted correctly to field-amplitude coefficients when inserted into Jones matrices.
4. Parameters that cannot be independently measured are explicitly labeled as unknown/nuisance parameters rather than silently interpreted as physical optic properties.
5. The phase-dependent power curves are then PREDICTED from the measured parameter set.
6. Agreement or disagreement with experiment is evaluated only after the parameter set has been fixed.

The central scientific question is:

    Can the measured physical imperfections of the real hybrid MZI explain the
    observed phase-dependent output amplitude without fitting the model to that
    amplitude behavior?

======================================================================
2. CRITICAL MODELING PRINCIPLE GOING FORWARD
======================================================================

DO NOT use the measured final power curves to determine nominally physical
parameters such as:

    - PBS leakage
    - beam-splitter mixing ratios
    - arm losses
    - retarder retardances
    - retarder axes

and then present the same final power curves as evidence that those physical
parameters explain the system.

That would be circular.

Instead:

    A. Measure the quantities independently.
    B. Lock them.
    C. Propagate the optical fields.
    D. Compare the resulting prediction to the measured phase-dependent power.

If some parameter cannot be independently measured, either:

    - leave it as an explicitly identified nuisance parameter,
    - place a physically justified prior/range on it,
    - or perform a separate dedicated measurement that constrains it.

Do not allow a fit to assign a precise physical meaning to an underconstrained
parameter.

======================================================================
5. RETARDANCE WARNING
======================================================================

Ordinary scalar power-meter measurements do NOT directly measure the
retardance of a lossless optical element.

For a unitary Jones retarder:

    ||J E||^2 = ||E||^2

so total power is unchanged.

Retardance can affect a later power measurement only indirectly when the
polarization state subsequently interacts with:

    - another polarization-dependent optic,
    - a polarizer/PBS,
    - or another coherent field at an interferometric recombination.

Therefore, if the input dataset contained only scalar powers, then fitted
values such as:

    retardance_c = +28.82 deg
    retardance_d = -34.96 deg

are inferred effective parameters, not direct measurements.

They may be compensating for any combination of:

    - actual retardance,
    - polarization-dependent beam-splitter phase,
    - PBS leakage,
    - spatial mode mismatch,
    - fiber-coupling mismatch,
    - beam walk,
    - incorrect arm-transmission coefficients,
    - other omitted degrees of freedom.

Codex should trace exactly which measurements constrain each fitted retarder
parameter and report parameter identifiability.


======================================================================
6. POSSIBLE POWER-VS-FIELD COEFFICIENT ERROR
======================================================================

Jones matrices multiply FIELD amplitudes.

If a power transmission is measured as:

    T_power = P_out / P_in

then the corresponding scalar field-amplitude coefficient is:

    t_field = sqrt(T_power)

not:

    t_field = T_power.

Historical measurements included approximately:

    P_A ~ 780 uW
    P_B ~ 880 uW

Power ratio:
    780 / 880 = 0.88636

Correct field-amplitude ratio:
    sqrt(780 / 880) = 0.94147

The current model contains:

    loss_a / loss_b
      = 0.655503 / 0.741261
      ~ 0.8843

This is suspiciously close to the measured POWER ratio rather than its square
root.

This does not prove the conversion was done incorrectly, because the origin of
those fitted values is not documented here.

However, it is important enough that the full parameter-generation path must
be audited.

For every scalar "loss" or "transmission" parameter, Codex should document:

    1. Original measured quantity.
    2. Units.
    3. Measurement plane.
    4. Whether it is a power quantity or field quantity.
    5. Exact conversion used before insertion into the Jones matrix.

7. POSSIBLE DOUBLE-COUNTING OF INPUT / ARM IMBALANCE
======================================================================

The current model separately contains:

    ay / ax = 1.02878

and also different A/B amplitude factors:

    loss_a = 0.65550
    loss_b = 0.74126

If both sets of parameters encode the same measured A/B power imbalance, then
the imbalance may be counted twice.

This must be resolved by defining a clear normalization plane.

For example, choose ONE of the following conventions:

OPTION A:
    ax, ay represent the field amplitudes incident on the PBS.
    PBS + downstream arm coefficients then describe all measured splitting and
    attenuation.

OPTION B:
    ax, ay are effective measured amplitudes at some post-PBS plane.
    In that case the PBS output imbalance should not be reintroduced through
    another independent A/B scaling parameter.

Every amplitude parameter needs an explicit physical plane.

======================================================================
9. NPBS1 SANITY CHECK FROM ISOLATED-PATH POWERS
======================================================================

Under a simple separable scalar-loss model, the cross ratio

    (P_AC * P_BD) / (P_AD * P_BC)

cancels the A/B source powers, C/D path losses, and downstream common factors.

For the zero-position data:

    (111 * 89) / (111 * 116)
      = 0.7672

which corresponds to approximately:

    T1 / R1 = sqrt(0.7672) = 0.876

or approximately a 46.7/53.3 beam splitter, depending on port labeling.

Repeating the same estimate for the other fiber positions gives approximately
46-47% for one branch, i.e. consistently close to 50/50.

The current fitted NPBS1 is approximately:

    65/35

which is substantially different.

CAVEAT:
The cross-ratio inference assumes separable scalar path transmission.
The existing spatial mismatch means that assumption may not be exact.

Still, the discrepancy is large enough that NPBS1 should be DIRECTLY measured
rather than inferred from the global fit.


======================================================================
10. SPATIAL-MODE PHYSICS IS CURRENTLY MISSING
======================================================================

This is one of the most important limitations.

The current report explicitly models:

    one spatial mode per path.

It does not model:

    - transverse beam displacement,
    - angular mismatch,
    - wavefront curvature mismatch,
    - different spatial modes for A/B-derived components,
    - fiber-mode overlap,
    - position-dependent coupling,
    - spatially varying polarization.

Historical experimental observations included:

    - two visibly separated spots on a camera,
    - changing input path changed spot position,
    - separation became clearer after long free-space propagation,
    - four isolated path combinations had different fiber-coupling maxima,
    - off-axis fiber scans changed AC/AD/BC/BD powers differently,
    - under phase modulation, separated spots showed different blinking
      behavior.

These are spatial-mode observations.

A pure 2-component Jones-vector model cannot represent them.

At minimum, the model should distinguish:

    polarization overlap

from:

    spatial overlap / detector-mode overlap.

For direct free-space detection, the relevant interference term is related to:

    integral C(r)^dagger D(r) dA

For single-mode fiber detection, the measured field is projected onto the fiber
mode u_f(r):

    A_p = integral u_f*(r) E_p(r) dA

and the detected power is:

    P_fiber proportional to sum_p |A_p|^2

A small displacement or angular mismatch can therefore produce phase-dependent
fiber-coupled power even if the total free-space power behaves differently.

The current fit may be forcing omitted spatial physics into effective Jones
retarders, scalar losses, PBS leakage, or beam-splitter ratios.


======================================================================
11. PHYSICAL INTERPRETATION OF THE CURRENT ~50% PHI2 FRINGE
======================================================================

The current model generates the large phi2-dependent intensity primarily
because the fitted C and D Jones transformations create substantial
polarization overlap at the final NPBS.

In an ideal hybrid MZI, the two relevant polarization components remain
orthogonal, so changing their relative phase does not strongly modulate total
port power.

Differential polarization transformation makes:

    C^dagger D != 0

and then the final scalar NPBS produces an interference term.

This is valid physics.

However, in the current model the amount of differential polarization
transformation was itself fitted.

Therefore the present result shows:

    "A model with this much effective C/D polarization mismatch can reproduce
     the observed qualitative behavior."

It does NOT yet show:

    "The real C and D paths have independently measured retardances that
     quantitatively explain the observed behavior."


======================================================================
12. RECOMMENDED REMEASUREMENT PROGRAM
======================================================================

The next dataset should be organized so every measurement has:

    - clear optical path,
    - clear blocked/unblocked arms,
    - measurement plane,
    - detector type,
    - polarization state if relevant,
    - raw power,
    - uncertainty / repeatability if practical.

Do not collapse measurements into fitted coefficients before saving them.


A. INPUT / PBS CHARACTERIZATION
-------------------------------

Measure known input H and V states separately.

For each input polarization, measure both PBS outputs.

Required results:

    P(A | H)
    P(B | H)
    P(A | V)
    P(B | V)

This directly constrains:

    - PBS extinction/leakage,
    - output power imbalance,
    - possible asymmetry between H and V.

If possible, repeat after rotating the input polarization by 90 degrees to
separate source-power drift from PBS behavior.

The model should use the measured FIELD coefficients:

    field coefficient = sqrt(power fraction).


B. NPBS1 DIRECT CHARACTERIZATION
--------------------------------

Do not infer NPBS1 splitting from the complete interferometer.

Inject one beam into one NPBS1 input port at a time.

Measure both output powers.

Repeat for:

    H input
    V input

if practical.

Record:

    T_H, R_H
    T_V, R_V

If H and V differ measurably, the NPBS should not be modeled as a scalar
polarization-independent splitter.

If only powers are measured, relative reflection/transmission PHASE remains
unmeasured and should not be silently assumed physical beyond the standard
chosen beam-splitter convention.


C. NPBS2 DIRECT CHARACTERIZATION
--------------------------------

Repeat the same procedure for NPBS2.

Measure H and V separately if possible.

Again distinguish measured intensity ratios from assumed complex phase
conventions.


D. A/B SCALAR TRANSMISSION
--------------------------

Define exact planes before and after the A and B path sections.

Block one path at a time.

Measure:

    P_A,in
    P_A,out

    P_B,in
    P_B,out

Then compute field transmission:

    t_A = sqrt(P_A,out / P_A,in)
    t_B = sqrt(P_B,out / P_B,in)

Do not use raw power ratios as Jones amplitude multipliers.


E. C/D SCALAR TRANSMISSION
--------------------------

Likewise define exact planes before and after C and D.

Measure each independently.

Avoid allowing spatially dependent fiber coupling to masquerade as free-space
arm transmission.

If the existing power meter measurement is taken THROUGH a fiber coupler,
label it specifically as:

    "effective coupling into monitored fiber mode"

rather than:

    "arm transmission."


F. C/D POLARIZATION TRANSFORMATION
----------------------------------

Use the PAX or equivalent polarimeter immediately before NPBS2.

Measure C alone and D alone.

At minimum, record the output Stokes/Jones state for a known input state.

Preferably perform several known input polarizations, e.g.:

    H
    V
    +45 deg linear
    optionally circular / elliptical if convenient

With multiple independent inputs, reconstruct an effective 2x2 Jones matrix
for each arm, up to an overall complex scalar.

This is much more defensible than fitting an arbitrary retarder axis and
retardance from scalar power data.

If the data only support a single output state for each arm, do NOT claim a
unique retarder Jones matrix.


G. SPATIAL CHARACTERIZATION
---------------------------

Characterize AC, AD, BC, and BD as spatial modes.

Useful measurements include:

    - camera centroid x/y at a fixed plane,
    - beam angle inferred from centroid at two longitudinal planes,
    - beam width,
    - beam ellipticity,
    - relative displacement,
    - relative angular mismatch,
    - fiber-coupling map versus x/y coupler position.

At minimum, store the four isolated fiber-coupling efficiencies at a common
coupler position.

Better:
perform a small x/y scan for each of AC, AD, BC, BD and fit the corresponding
coupling surfaces.

The eventual model should include at least effective complex spatial-overlap
factors for interfering components.

======================================================================
14. SPATIAL EXTENSION RECOMMENDATION
======================================================================

Do not immediately build a full diffraction simulation unless necessary.

A useful intermediate model may represent each relevant field as:

    Jones vector x scalar spatial-mode amplitude

with pairwise complex overlap coefficients.

For example, at the final NPBS:

    E_E = t C + i r D

but detected power may use:

    I_E =
        t^2 ||C||^2
        + r^2 ||D||^2
        + 2 t r Re[i * Gamma_CD * (C_pol^dagger D_pol)]

where:

    Gamma_CD

is a complex normalized spatial overlap factor.

For a single-mode fiber detector, Gamma should represent overlap after
projection into the monitored fiber mode.

This separates:

    polarization mismatch
from
    spatial mismatch

instead of forcing one to impersonate the other.

If the system requires more detail later, extend to explicit transverse fields.

16. PARAMETER IDENTIFIABILITY REQUIREMENT
======================================================================

Before reporting a fitted physical parameter, test whether the available data
uniquely constrain it.

At minimum:

    - report sensitivity/Jacobian,
    - report strong parameter correlations,
    - test multiple random initializations,
    - inspect whether very different parameter sets yield similar residuals,
    - compute confidence intervals or profile likelihoods if feasible.

If retardance, axis, loss, PBS leakage, and spatial overlap trade off strongly,
do not assign a unique physical interpretation.

The model should be allowed to conclude:

    "these data do not determine this parameter."

That is preferable to inventing precision.

======================================================================
19. SUCCESS CRITERIA
======================================================================

The model will be considered physically convincing if:

1. Beam-splitter ratios, PBS leakage, arm transmissions, polarization
   transformations, and detector/spatial overlap are independently measured.

2. These measurements are entered into the forward model without fitting them
   to the final phase-dependent power curve.

3. The resulting model predicts the observed phi1- and phi2-dependent
   amplitudes within experimental uncertainty.

4. It also reproduces independent polarization observations and isolated-path
   measurements.

5. A materially different set of physical parameters is not equally capable
   of reproducing all observables.

If the measured model FAILS to reproduce the observed phase-dependent
amplitude, that is a useful result.

It means an important physical degree of freedom is still missing.

The correct response is then to identify and measure that missing physics,
not to force existing physical parameters to absorb the discrepancy.


======================================================================
20. CORE PRINCIPLE
======================================================================

The system should determine the model.

The model should not determine the system.

We are trying to answer:

    "Given what the apparatus physically measures to be, does the predicted
     optical behavior match what the apparatus actually does?"

We are NOT trying to answer:

    "What set of Jones parameters can be found that makes the plots look like
     the experiment?"

Those are fundamentally different scientific tasks.

For this project, only the first one is the target.
