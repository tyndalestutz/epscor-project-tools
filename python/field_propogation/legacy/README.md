# Earlier interactive explorations

Preserved standalone plotting scripts. Start new parameterized Jones work with
[the current models](../README.md). These scripts create plots at module scope
and should be run directly, not imported as a simulation library.

- `optics.py`, `optics-compiled.py`: symbolic optics propagation with sliders.
- `poincare_from_symbo.py`: interactive symbolic-field Poincaré visualization.
- `poincare_from_symbo-static.py`, `poincare_from_symbo-static-2.py`: static variants.
- `demo-poincare.py`: Poincaré plotting demonstration.

The names and calculations are preserved; “legacy” does not imply the variants
are equivalent or that their port/Stokes conventions match the current models.
