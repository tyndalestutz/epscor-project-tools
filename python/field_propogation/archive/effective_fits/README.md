# Archived effective fits — not measured optic properties

These scripts and their original algorithms are retained only to reproduce
historical results. No active measurement-to-model path imports an optimizer.
The former "physical Jones fit" jointly adjusted 17 coordinates using final
PD/PAX powers and both-path PAX Stokes data. Its output was not an independent
measurement of retardance, leakage, splitting ratios or arm transmission.

See [the audit](../../docs/historical_fit_audit.md). Raw historical experiment
files are preserved; this is a correction of their interpretation, not a
replacement of the evidence. Run these scripts only for historical reproduction.
