# EPSCoR project tools

- [Jones-field simulations](python/field_propogation/README.md): ideal and
  parameterized hybrid-MZI models, measured configurations, and reference explorations.
- [Polarization locking](python/polarization_locking/README.md): numbered bench diagnostics, reusable recipes, and
  live control; [offline bench diagnostics](python/polarization_locking/analysis/README.md).
- [Polarization visualization](python/polarization_visualization/README.md).
- [Experiments](experiments/README.md): recorded runs and analysis artifacts.
- `notebooks/`: exploratory notebooks; `data/`, `papers/`, and `reports/`:
  supporting data, literature, and documents.

- [Independent hybrid-MZI measurement acquisition](python/field_propogation/docs/measurement_acquisition.md): named planes, raw-reading templates, provenance, frozen predictions and held-out comparison.
- [Historical fit audit](python/field_propogation/docs/historical_fit_audit.md): corrected interpretation and identifiability evidence.
